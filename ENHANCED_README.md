# Decentralized Insurance Protocol

Decentralized insurance protocol for DeFi positions with parametric triggers and automated claims processing.

## Features
- Parametric insurance products
- Automated claims using oracles
- Risk pooling and pricing engine
- Multi-protocol coverage
- Governance for product parameters

## Architecture
- Insurance core contracts
- Oracle integration for triggers
- Claims processing module
- Risk and pricing engine
